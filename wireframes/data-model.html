🗄 Data Model
Cloudflare D1 (SQLite) schema · claims, reports, sources, subscribers, channels, audit log
Entity Overview
8 core tables. Claims is the central entity — everything else references it.
Database: Cloudflare D1 (SQLite at the edge). All queries run in the same Worker process — no network round-trip to a database server. Free tier: 5 GB storage, 25 M row reads/day, 100 K row writes/day.
