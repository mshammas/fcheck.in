🏗 Backend Architecture
Cloudflare edge stack · AI pipeline · Bot integrations · API design
Infrastructure Overview
All layers run on Cloudflare's edge network — no traditional server infrastructure. Workers execute at the nearest PoP to the user.
☁ Cloudflare Edge Network
Cloudflare Pages
Static asset hosting + CI/CD. GitHub push → auto-deploy. Preview deployments per branch.
Cloudflare Workers
Serverless functions. Handle API routes, bot webhooks, AI pipeline, background jobs. V8 isolates — cold start ~0ms.
Cloudflare D1
SQLite at edge. Claim store, reports, fact-checkers, subscribers, audit log. Free tier: 5GB storage, 25M reads/day.

API Design
Public REST API. All endpoints return JSON. Authentication via Bearer token for write endpoints.
MethodEndpointAuthDescription
POST/api/v1/checkNone (public)Submit a claim for fact-checking. Returns TYPE 1–4 response with verdict, confidence, sources.
GET/api/v1/claims/:idNoneRetrieve a specific claim by ID.
GET/api/v1/search?q=…NoneSearch published claims by text similarity.
POST/api/v1/subscribeNoneSubscribe to notifications for a claim ID via email or phone.
GET/api/v1/trendingNoneReturn current trending queue (pinned + active cards).
POST/api/admin/drafts/:id/publishAdmin tokenPublish a reviewed draft as a TYPE 1 article.
POST/api/admin/drafts/:id/rejectAdmin tokenReject a draft.
PUT/api/admin/drafts/:idAdmin tokenUpdate draft fields (verdict, headline, summary, evidence).
POST/api/admin/trendingAdmin tokenAdd a card to the trending queue.
DELETE/api/admin/trending/:idAdmin tokenRemove a card from the trending queue.
